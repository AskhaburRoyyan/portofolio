# Portofolio Askhabur Royyan

Website portofolio statis (HTML, CSS, JavaScript tanpa framework).

## Cara mengubah isi

Semua konten ada di **`data.js`**: profil, kontak, keahlian, dan proyek.
Kolom yang dikosongkan (`""` atau `[]`) otomatis tidak ditampilkan.

## Menambah screenshot proyek

1. Taruh foto di `assets/img/projects/` (format .jpg, lebar ±1600px).
2. Tulis nama filenya di bagian `images` proyek tersebut di `data.js`.
   Foto pertama dipakai sebagai sampul.

Kalau file fotonya belum ada, halaman menampilkan kotak "Screenshot belum ditambahkan".
